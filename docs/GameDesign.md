# World Creator
# Game Design Document


## 1. 概要

World Creator は、世界創造をテーマとした放置型シミュレーションゲームである。

プレイヤーは資源を獲得し、世界を発展させ、生命・文明・研究・戦闘などの要素を通じて新たな世界を構築する。


---

## 2. 基本システム


### 資源

世界を成長させるための基本要素。

例：

- 木材
- 石材
- 食料
- 魔力
- 知識


資源は時間経過や施設、アップグレードによって増加する。



### 世界発展

生成された世界を発展させる。

発展によって以下が解放される。

- 新規資源
- 技術
- 生物
- 建築
- 戦闘要素



### 放置進行

ゲームを閉じている間も時間経過による進行を計算する。

ただし、設定された最大時間を超える放置時間は制限される。



---

## 3. 成長システム


### アップグレード

資源を消費して能力を強化する。

種類：

- 生産強化
- 世界強化
- 戦闘強化
- 研究強化



### 研究

知識を使用して新しい能力やシステムを解放する。

研究には段階が存在し、高度な研究ほど必要コストが増加する。



### 成長ツリー

複数の成長経路を持つ。

現在予定：

- Life Tree
  - 生命
  - 成長
  - 発展

- Death Tree
  - 終焉
  - 破壊
  - 変換


各ツリーの組み合わせによって特殊効果が発生する。



---

## 4. 戦闘システム


世界には敵対存在が出現する。

戦闘では以下を使用する。

- プレイヤー能力
- 敵能力
- 強化効果
- 研究効果


勝利によって報酬を獲得する。



---

## 5. ガチャ・奉納


### ガチャ

特殊アイテムを取得するシステム。

アイテムには以下の要素を持つ。

- 種類
- 希少度
- 効果



### 奉納

不要なアイテムや資源を変換し、新しい力を得る。

Life Tree、Death Treeとの関連要素として利用する。



---

## 6. 保存システム

保存方式：

- LocalStorage

保存対象：

- 資源
- 世界状態
- アップグレード
- 研究状態
- 時間情報


---

## 7. 技術仕様

対応：

- HTML
- CSS
- JavaScript

形式：

- SPA
- PWA


主要システム：

- EventBus
- 自作BigNumber
- LocalStorage Save System


---

## 8. 開発方針

拡張性を重視し、各システムを独立したモジュールとして管理する。

新規要素追加時は既存システムへの影響を最小限にする。
